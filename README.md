# 米道 KOMEDO — 稲作経営シミュレーション

稲作経営を体験するブラウザゲームです。作付、農地、機械、人、販売、お金のやりくりを毎年自分で決め、天候や米価の変化を乗り越えながら、経営を続けることをめざします。

## 2つのモード

- **📖 ストーリーモード**：3つの物語から選べます。章、地域の人からの依頼、5年目に選ぶ「経営の道」、1年前に予告される試練の年（冷夏・米価暴落・猛暑）があり、物語ごとの「約束」を果たせるかで、エンディングが変わります。作れる品種も最初は少しだけで、面積を広げる、品質を上げる、お客さんを増やす、地域の信頼を得る、といったことをきっかけに増えていきます。品種だけでなく、特別栽培・有機栽培・直播、正社員の雇用、収入保険、認定農業者（低利の制度資金）、中古機械・リース・大型の機械、作業受託・直売所・加工場なども、きっかけを満たすと使えるようになります（ホームの「これから使えるようになるもの」で確かめられます）。
  - **じいちゃんの田んぼ**（20年）：腰を痛めたじいちゃんから2haの田んぼを託され、機械もやり方もわからないところから経営を大きくしていきます。
  - **山あいの棚田を守れ**（20年）：高齢化の進む山あいの集落で、毎年「田んぼを預かってほしい」と頼まれます。断ると田んぼは荒れてしまいます。手間のかかる棚田を、売り方と人の工夫で守ります。
  - **農業法人を立て直せ**（15年）：借入5,200万円・古い機械・赤字の契約をかかえた40haの法人を引き継ぎます。3年目と5年目に融資の審査があり、決算書を読んで立て直します。
- **🏡 自分の経営モード**：今の経営を入れて、この先どうなるかを試せます。区切りなく続けられ、5年ごとに中間評価があります。好きなところで締めくくると、最終評価と「今のやり方のまま続けたらどうなるか」の見立てが出ます。用意された経営（新規就農・親元就農・法人参入）で遊ぶこともできます。

新しく農業を始める人、農業を学ぶ学生、そして今の経営をこの先どうしていくか考えたい農家の方に向けて作りました。

スマホでもパソコンでも、インストールなしでブラウザで遊べます。

## どんなゲーム？

- **毎年の経営計画**：品種ごとの作付面積、農地の借り入れ、機械を買うか委託するか、パートや社員の雇用、農協・契約・直販の売り分け、借入や保険を決めます。右側に今年の見通しが出ます。
- **1か月ずつ進むシーズン**：田植えから稲刈りまで、月ごとのできごとと、お金の出入りが分かります。秋まで売上が入らない資金繰りの大変さも体験できます。
- **決算で振り返る**：損益計算書・貸借対照表・資金繰り表・原価分析と、JA営農指導員の高橋さんの講評で、1年を振り返ります。
- **サイコロ**：年の初めの「運だめし」で幸運・不運のカードを引き、病気の注意報や台風では「対策するか、サイコロで勝負するか」を選びます。
- **地域の人たち**：規模拡大型の大山さん、こだわり直販型の小川さん、兼業の田村さんと、同じ集落で経営を競います。地主さん、米卸の取引先、農業を学びたい若者との続きものの話もあります。
- **新しい事業**：作業受託、ドローン防除、餅・米粉の加工、直売所、米を保管して春に売る、などにも挑戦できます。
- **評価**：5年ごとに中間評価、経営を終えるときに最終評価（S〜D）があり、称号も集められます。

## 自分の経営で試す

「自分の経営モード」で「自分の経営」を選ぶと、今の経営（家族の年齢、後継者、農地、品種、機械の大きさと使用年数、借入など）を入れて、この先の経営を体験できます。締めくくったあと、「今のやり方のまま続けたらどうなるか」を天候を変えて何通りも試算し、高橋さんが見立てを話してくれます。

## 感想を送ってください

ゲームをよりよくするため、感想を集めています。

- 遊んでいる途中に気づいたことは、上のバーの「💬」ボタンから送れます。
- 経営を終えたあとの画面に、短いアンケートがあります。

送られるのは、書いた内容と、ゲームの中の数字（毎年の判断と結果）だけです。農場名・名前・地名は送りません。「自分の経営」で遊んだ場合も、送るのは面積や金額などの数字だけで、送るかどうかは毎回選べます。

## そのほか

- セーブは、遊んでいるブラウザの中に保存されます。
- 品種は新潟県の主な品種をもとにしています。取引先・人物・制度の一部は架空で、数値は学習用に単純化しています。実際の経営判断は、地域の指導機関や専門家にご相談ください。
